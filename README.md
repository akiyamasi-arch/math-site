# 数学学習サイト

生徒向けに公開する教材（シミュレーションアプリ・プリント・参考動画）をまとめたサイトです。

## サイトの構成（トップ → 科目 → 単元）

ページは3種類だけで、科目・単元・教材の一覧はすべて `data/` のデータから自動生成されます。

```
トップページ（index.html）… 青い星雲の中から科目ボタンを選ぶ入り口
  ※ 開いた直後に「MATHEMATICS」のオープニングが約2秒出る（ブラウザを開いてから最初の1回だけ／タップで飛ばせる／`assets/intro.js`。やめる場合は index.html の `<div class="intro">` と intro.js の読み込みを消す）
  ├─ 科目ボタン（数学Ⅰ・A・Ⅱ・B・Ⅲ・C、内容に合わせたアイコン付き）＋「数学いろいろ」
  ├─ お知らせ・更新情報（教材・記事の追加日から自動生成 ＋ 手書きのお知らせ）
  ├─ 数学いろいろ（最新3件）
  └─ 数学の勉強のヒント
      ├─ 科目ページ（subject.html?s=math1）… その科目の単元一覧
      │   └─ 単元ページ（unit.html?s=math1&u=nijikansu）… アプリ／プリント／動画
      └─ 数学いろいろ（iroiro.html）… 読みもの・面白い話題
```

```
生徒向けサイト/
├── index.html          … トップページ
├── subject.html        … 科目ページ（URLの s= で科目を指定）
├── unit.html           … 単元ページ（URLの s= と u= で科目・単元を指定）
├── iroiro.html         … 数学いろいろ
├── furikaeri.html      … 振り返りGEM（どの単元でも使えるAIのふり返り）
├── assets/
│   ├── style.css       … 共通スタイル（デジタル庁デザインシステム準拠）
│   ├── site.js         … 共通スクリプト（データからページを組み立てる）
│   └── hero.js         … トップページの霧の背景アニメーション
├── data/
│   ├── curriculum.js   … 科目と単元の一覧（サイトの「部屋」の設計図）
│   ├── apps.js         … シミュレーションアプリの一覧
│   ├── prints.js       … プリント・教材の一覧
│   ├── videos.js       … 参考動画の一覧
│   ├── gems.js         … 振り返りGEM（Geminiの共有リンク）の一覧
│   ├── topics.js       … 数学いろいろの記事
│   ├── news.js         … 手書きのお知らせ
│   └── tips.js         … 勉強のヒント（トップページ）
├── apps/               … アプリ本体（HTML）
├── <単元名>/            … PDFなどの実ファイルを置くフォルダ（例: 2次関数/）
├── 教材リスト.xlsx      … 追加したい教材を書き込むExcelファイル（このフォルダにのみ存在し、GitHubには上げない）
└── README.md           … このファイル
```

- 科目・単元は `data/curriculum.js` に書いた順に並びます。教材がまだ無い単元も「準備中」として最初からページが用意されます
- 教材データ（apps / prints / videos）の `subject` と `unit` は、`curriculum.js` の科目名・単元名（日本語）と一致させます。「数学Ⅰ」「数学I」のような表記ゆれは自動で吸収されます
- 各教材の `added`（追加日）から、トップページの「更新情報」が自動で作られます

## 教材を追加するときの流れ

### 科目・単元（部屋）を増やす場合
`data/curriculum.js` の該当科目の `units` に `{ id: "半角英数字", name: "単元名" }` を1つ足すだけです。科目を増やす場合も同様に科目のブロックを追加します。

### お知らせを書く場合
`教材リスト.xlsx` の「お知らせ」シートに日付と内容を書く（または `data/news.js` に `{ date: "2026-09-08", text: "…", url: "" }` を1件足す）。教材の追加は自動で載るので、ここには「テスト範囲を載せました」などの連絡事項を書きます。

### 数学いろいろに記事を書く場合
`data/topics.js` に `{ title, body, url, urlLabel, added }` を1件足します。`body` の改行は `\n` で入れられます。`added`（追加日）を入れると更新情報にも自動で載ります。文章をチャットで渡してもらえれば、こちらで追加します。

### 勉強のヒントを直す場合
`data/tips.js` の `title` / `body` を書き換えます。

### 振り返りGEMを追加する場合
`data/gems.js` に1件足します（GEMの名前と共有リンクを表やExcelで渡してもらえれば、こちらで追加します）。
- 単元専用のGEM：`subject` と `unit` を書く → その単元ページの一番下に「振り返りGEM」欄が出ます（GEMが無い単元では欄は出ません）
- どの単元でも使えるGEM：`common: true` と書く → 「振り返りGEM」ページ（`furikaeri.html`）に出ます。このページへは、トップの「振り返りGEM」ボタン・上部メニュー・各単元ページの一番下の案内から入れます

### アプリ（HTML）を追加する場合
1. `apps/` フォルダにHTMLファイルを追加する
2. `data/apps.js` に1件追加する（科目・単元・タイトル・説明・ファイルパス・追加日）

### プリント・動画を追加する場合（`教材リスト.xlsx` を使う）

このフォルダにある **`教材リスト.xlsx`** に直接書き込む方法が一番簡単です。

1. `教材リスト.xlsx` を開く（「使い方」シートに手順の説明あり）
2. 「プリント」シートまたは「動画」シートに1行追加する。「科目」「単元」の列はセルを選ぶと▼が出て、リストから選べます（リストに無いものは直接入力も可）
   - プリントの場合：PDFファイル自体は、単元名のフォルダ（例: `2次関数/`）に置く。フォルダが無ければ新規作成でよい
   - 動画の場合：YouTubeの動画URL（例: `https://youtu.be/xxxxxxxxxxx`）をそのまま貼り付ける。他人の動画は埋め込み表示のみとし、ファイルを保存してアップロードし直すのはNG（著作権）
3. 保存して「教材リストを更新して」と伝える → `data/prints.js` / `data/videos.js` / `data/news.js` への反映とGitHubへのpushまで対応します

`教材リスト.xlsx` はこのフォルダにのみ置く編集用ファイルで、`.gitignore` によりGitHub（公開リポジトリ）には上げない設定にしてあります。ドロップダウンの選択肢は「リスト」シートにあり、科目・単元を増やすときは `data/curriculum.js` と合わせて更新します。

### （参考）データファイルを直接編集する場合
Excelを使わない場合は、`data/prints.js` / `data/videos.js` の配列に直接オブジェクトを1件追加することでも反映できます（科目・単元・タイトル・ファイルパス／YouTube ID）。

### GitHubへの反映（共通）

```bash
git add .
git commit -m "add: 〇〇を追加"
git push
```

数分待つと公開サイトに反映されます。

### 更新時のルール：CSS/JSの版番号を上げる
ブラウザは `assets/*.css` `assets/*.js` `data/*.js` を最大10分ほど手元に保存（キャッシュ）します。古いCSS/JSと新しいHTMLが混ざると表示が崩れるので、各HTMLの読み込みURLに付いている `?v=20260908b` のような版番号を、**サイトを更新するたびに新しい値に揃えて書き換えます**（5つのHTMLすべて）。この作業は更新作業とセットでこちらで行います。

一括で書き換えるコマンド（Git Bash）：

```bash
VER=20260910a
for f in index.html subject.html unit.html iroiro.html furikaeri.html; do
  sed -i -E "s#(src|href)=\"(assets|data)/([A-Za-z0-9_.-]+\.(js|css))(\?v=[0-9a-z]+)?\"#\1=\"\2/\3?v=$VER\"#g" "$f"
done
```

それでも古い表示が出るときは、ブラウザで `Ctrl + F5`（スーパーリロード）を押してください。

## 公開URL

GitHub Pagesを有効化すると、以下のような形のURLになります（リポジトリ名は実際のものに置き換え）：

```
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

## 注意事項

- **このフォルダには「生徒に見せてよいもの」だけを置く。** 個人情報を含む資料（名簿、指導要録、成績など）は絶対に入れない
- 他人が作った動画やアプリを直接コピーして置くのはNG。リンク（埋め込み）にする
- ファイル名はできるだけ半角英数字にする（日本語ファイル名だとURLが長くなり共有しづらいため）
