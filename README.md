# 数学学習サイト

生徒向けに公開する教材（シミュレーションアプリ・プリント・参考動画）をまとめたサイトです。

## 構成

```
生徒向けサイト/
├── index.html         … トップページ（データを読み込んで一覧を自動表示）
├── apps/               … シミュレーションアプリ（HTML）
│   └── quadratic-inequality.html
├── data/
│   ├── prints.js       … プリント・教材の一覧データ
│   └── videos.js       … 参考動画の一覧データ
├── <単元名>/            … PDFなどの実ファイルを置くフォルダ（例: 2次関数/）
├── 教材リスト.xlsx      … 追加したい教材を書き込むExcelファイル（このフォルダにのみ存在し、GitHubには上げない）
└── README.md           … このファイル
```

プリントと動画は、`index.html` を直接書き換えるのではなく **`data/prints.js` と `data/videos.js` にデータを1件追加するだけ** で一覧に反映される仕組みになっています（見た目は自動的に整います）。

## 教材を追加するときの流れ

### アプリ（HTML）を追加する場合
1. `apps/` フォルダにHTMLファイルを追加する
2. `index.html` の「シミュレーションアプリ」セクションにカードを1つ追加する

### プリント・動画を追加する場合（`教材リスト.xlsx` を使う）

このフォルダにある **`教材リスト.xlsx`** に直接書き込む方法が一番簡単です。

1. `教材リスト.xlsx` を開く（「使い方」シートに手順の説明あり）
2. 「プリント」シートまたは「動画」シートに1行追加する
   - プリントの場合：PDFファイル自体は、単元名のフォルダ（例: `2次関数/`）に置く。フォルダが無ければ新規作成でよい
   - 動画の場合：YouTubeの動画URL（例: `https://youtu.be/xxxxxxxxxxx`）をそのまま貼り付ける。他人の動画は埋め込み表示のみとし、ファイルを保存してアップロードし直すのはNG（著作権）
3. 保存して「教材リストを更新して」と伝える → `data/prints.js` / `data/videos.js` への反映とGitHubへのpushまで対応します

`教材リスト.xlsx` はこのフォルダにのみ置く編集用ファイルで、`.gitignore` によりGitHub（公開リポジトリ）には上げない設定にしてあります。

### （参考）データファイルを直接編集する場合
Excelを使わない場合は、`data/prints.js` / `data/videos.js` の配列に直接オブジェクトを1件追加することでも反映できます（科目・単元・タイトル・ファイルパス／YouTube ID）。

### GitHubへの反映（共通）

```bash
git add .
git commit -m "add: 〇〇を追加"
git push
```

数分待つと公開サイトに反映されます。

## 公開URL

GitHub Pagesを有効化すると、以下のような形のURLになります（リポジトリ名は実際のものに置き換え）：

```
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

## 注意事項

- **このフォルダには「生徒に見せてよいもの」だけを置く。** 個人情報を含む資料（名簿、指導要録、成績など）は絶対に入れない
- 他人が作った動画やアプリを直接コピーして置くのはNG。リンク（埋め込み）にする
- ファイル名はできるだけ半角英数字にする（日本語ファイル名だとURLが長くなり共有しづらいため）
