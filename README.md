# 数学学習サイト

生徒向けに公開する教材（シミュレーションアプリ・プリント・参考動画）をまとめたサイトです。

## 構成

```
生徒向けサイト/
├── index.html        … トップページ（教材への入り口）
├── apps/              … シミュレーションアプリ（HTML）
│   └── quadratic-inequality.html
└── README.md          … このファイル
```

## 教材を追加するときの流れ

1. 新しいアプリやプリントができたら、このフォルダの中に追加する
   - アプリ（HTML）は `apps/` フォルダへ
   - プリント（PDF）は `prints/` フォルダを作って入れる、など
2. `index.html` にカードを1つ追加して、そのファイルへのリンクを書く
3. GitHubに反映する（下記コマンド）

```bash
git add .
git commit -m "add: 〇〇を追加"
git push
```

4. 数分待つと公開サイトに反映されます

## 公開URL

GitHub Pagesを有効化すると、以下のような形のURLになります（リポジトリ名は実際のものに置き換え）：

```
https://<GitHubユーザー名>.github.io/<リポジトリ名>/
```

## 注意事項

- **このフォルダには「生徒に見せてよいもの」だけを置く。** 個人情報を含む資料（名簿、指導要録、成績など）は絶対に入れない
- 他人が作った動画やアプリを直接コピーして置くのはNG。リンク（埋め込み）にする
- ファイル名はできるだけ半角英数字にする（日本語ファイル名だとURLが長くなり共有しづらいため）
